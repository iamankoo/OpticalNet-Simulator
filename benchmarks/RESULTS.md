# OpticalNet benchmark results

Generated by `benchmarks/report.py` from raw JSON produced by `opticalnet_bench` and `bench_api.py`. Every number below was measured; nothing is estimated.

**Environment:** GitHub Codespace (4 vCPU AMD EPYC 7763, 16 GB RAM), Ubuntu 24.04, GCC 13.3 -O3 with LTO, CMake 3.28, Python 3.13.8, FastAPI 0.162.0, Pydantic 2.14.1

**Method:** each benchmark is run with 3 repetitions per run and the median is taken; the before/after binaries were run alternately (2 runs each) on the same machine, and the table shows the mean of the per-run medians. "Before" is the code at commit `44755a7` (end of Phase 9); "after" is the Phase 10 code. Speedup = before / after. Fixed seeds and generated topologies make the workloads identical in both builds; the checksum column confirms the computed results are bit-identical.

In-process TestClient request floor (`GET /health`, no engine call): 3.54 ms per request. The `http.*` rows above include this fixed cost, which is why routing requests, whose engine time is below 0.1 ms, show no speedup through HTTP even though the direct binding call is faster.
